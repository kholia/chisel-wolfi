# Wolfi Node Build

Builds a chiseled Wolfi Node.js build image with npm, yarn, pnpm, Python,
Git, curl, and a native C/C++ build toolchain.

```sh
make -C examples/wolfi-node-build build
make -C examples/wolfi-node-build test
make -C examples/wolfi-node-build size
make -C examples/wolfi-node-build scan
```
