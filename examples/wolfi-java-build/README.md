# Wolfi Java Build

Builds a chiseled Wolfi OpenJDK build image with Maven, Git, curl, jq,
unzip, and a native C/C++ build toolchain.

```sh
make -C examples/wolfi-java-build build
make -C examples/wolfi-java-build test
make -C examples/wolfi-java-build size
make -C examples/wolfi-java-build scan
```
