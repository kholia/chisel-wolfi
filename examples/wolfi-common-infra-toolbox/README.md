# wolfi-common-infra-toolbox

Builds an infra CI toolbox with Docker, AWS CLI, gcloud, GKE auth plugin, kubectl, Helm, Terraform, OpenBao, Flux, argo rollouts, grpc-health-probe, buf, uv, jq, yq, yamllint, git, curl, wget, rsync, and archive utilities.

```sh
make -C examples/wolfi-common-infra-toolbox all
```
